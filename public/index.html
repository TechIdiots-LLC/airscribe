                              RadioReference

                              For the Map’s Find: a channel’s frequency is looked up in RadioReference, in the county of the ZIP code here (the state’s, if the county has nothing), and so is where the FCC licence for it says the transmitter is. It needs a RadioReference Premium subscription, and an app key for AirScribe, which RadioReference issues to developers (apply here). The password and key are kept on this server and not shown again.

                              Uniden’s database

                              Also for the Map’s Find, with RadioReference or without it: the database the SDS100, SDS150, SDS200 and BCDx36HP scanners carry, which gives each frequency and talkgroup a place and a range. Choose a .zip of the BCDx36HP/HPDB folder on the scanner’s SD card (the scanner in mass storage mode, or the card in a reader; in Windows, right-click the folder → Send to → Compressed (zipped) folder), or the folder itself, then the states your radios hear, with their neighbours near a border. Sentinel writes the same folder when it updates the card. A channel the scanner named is found by that name, which is the database’s own.

                              Findings

                              A language model reads each transcript, with the channel’s last few minutes, and picks out the addresses, roads, plates, vehicles, people and units mentioned, the kind of call and a one-line summary. It runs on a server you give here: an Ollama (llm-lxc’s, say) or another OpenAI-style one. What it finds is about people heard on the radio, so only signed-in users see it, on the Findings tab: never the feed or the public view. It’s deleted after the days set here. Speech recognition mishears radio, and a model can turn a misheard word into a confident wrong one: play the clip before acting on anything (docs/findings.md).

                              Given with each transmission: more is more for the model to read, and slower.

                              Roads

                              The roads around the channels, from OpenStreetMap. With each transmission, the model is given those near its channel whose names sound like something said, so a road speech recognition misheard comes back as the one that’s there; and the roads mentioned light up on the Map (Roads mentioned). Read them from the map’s own tiles (OpenMapTiles), fetch them from OpenStreetMap, for the area around the channels placed on the map, or import a GeoJSON file made from an OpenStreetMap extract (docs/findings.md#roads). Only the area is sent to get them, nothing heard.

                              What it finds, and the watch list, are on the tab.

                              Findings

                              Watch for

                              A plate, a street, a name, a phrase. Each is looked for in the transcript and in what the model found: “Elm St” finds “412 Elm Street”, and “ABC 123” finds a plate read out as “Adam Boy Charlie one two three”. A match is kept here and posted to the webhook. Admins add and remove them.
