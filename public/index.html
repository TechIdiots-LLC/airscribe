                    Sign-in providers

                    People can sign in with Google, GitHub, Discord or Facebook once they’ve linked it under their account. For each provider: make an OAuth app in its console, give it the redirect URI shown here exactly, and enter its client ID and secret. A provider only sends people back to an address registered with it, so this server needs one they can reach (Google takes http:// only for localhost; see docs/linked-logins.md).

                      RadioReference

                      For the Map’s Find: a channel’s frequency is looked up in RadioReference, in the county of the ZIP code here (the state’s, if the county has nothing), and so is where the FCC licence for it says the transmitter is. It needs a RadioReference Premium subscription, and an app key for AirScribe, which RadioReference issues to developers (apply here). The password and key are kept on this server and not shown again.
